# Evidence directory

This directory contains templates only. It does not contain proof of deployment.

Use [evidence-template.md](evidence-template.md) after a real, authorized run.
Prefer concise Markdown summaries over screenshots. Store raw output privately,
redact it, and review the sanitized artifact before committing.

Never commit subscription, tenant, principal, or resource IDs; receiver addresses;
access tokens; portal URLs containing identifiers; deployment output; or billing
documents. Do not create example output that could be mistaken for a real run.
